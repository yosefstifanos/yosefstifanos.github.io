## 🔬 Projects

### 🤖 BoM Squad
Multi-agent AI pipeline that converts engineering requirements into a draft Bill of Materials in minutes: PDF ingestion → Azure AI Search catalog research → automated BoM assembly → engineer-facing chatbot. Achieved 100%+ of project goals across all 7 deliverables; estimated $100k+/yr value per team and 15 hrs/week saved.
Technologies: `Python`, `Azure AI Search`, `Multi-Agent Systems`, `LLM`

### 🔐 [NIST Password Generator + Passphrase Tool](https://yosefstifanos.github.io/projects/NIST.html)
Generates strong, random passwords that meet NIST SP 800-63B guidelines, checks passwords against known breaches via the Have I Been Pwned API (k-anonymity), and generates secure Diceware-style passphrases.
Technologies: `HTML`, `CSS`, `JavaScript`, `Web Crypto API`, [Have I Been Pwned API](https://haveibeenpwned.com/API/v3#PwnedPasswords)

### 🏀 [March Madness ML Simulator](https://yosefstifanos.github.io/projects/mm26.html)
25 seasons of historical data, KenPom efficiency ratings, and Vegas lines fed into an ensemble model running 100,000 simulated tournaments to generate bracket picks with win probabilities.
Technologies: `Python`, `Scikit-learn`, `Monte Carlo`

### 📋 OSCAL Compliance Automation
End-to-end compliance data pipeline integrating OSCAL-formatted control data with ServiceNow IRM transform maps and Snowflake.
Technologies: `OSCAL`, `ServiceNow IRM`, `NIST RMF`

### ✝️ [Concordia](https://yosefstifanos.github.io/projects/concordia.html)
An LCMS confessional study assistant grounded in the Book of Concord and Luther's writings, with live web verification against current LCMS/CTCR positions and built-in debate prep across Christian traditions.
Technologies: `Claude API`, `Web Search Tool`, `Book of Concord`

### ⚽ [Red Resilience](https://yosefstifanos.github.io/projects/red_resilience_website.html)
An interactive longform feature on Manchester United's 2024/25 season, exploring resilience and loyalty through scroll-triggered reveal animations, key stats, and fan voices.
Technologies: `HTML`, `CSS`, `JavaScript`, `Scroll Animation`

### 🎮 [Game Sales Prediction & Playtime Classification](https://github.com/yosefstifanos/final_project)
Regression and classification models forecasting video game sales and playtime behavior, evaluated with R², RMSE, and AUC.
